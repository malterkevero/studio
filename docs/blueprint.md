# **App Name**: Kaptár Napló

## Core Features:

- Kaptár hozzáadás: Lehetővé teszi új kaptárak hozzáadását az alkalmazáshoz.
- Kaptár szerkesztés: Lehetővé teszi a meglévő kaptárak adatainak szerkesztését.
- Kaptár törlés: Lehetővé teszi a kaptárak törlését a rendszerből.
- Adat exportálás CSV-be: Lehetővé teszi a kaptárak adatainak exportálását CSV formátumba.
- Offline tárolás: Az adatok tárolása offline módban a localStorage-ban.

## Style Guidelines:

- Primary color: Aranysárga (#FFC107) a mézre utalva, de nem túl élénk.
- Background color: Világos bézs (#F5F5DC), hogy a sárga kiemelkedjen.
- Accent color: Sötét narancs (#FF8A65) a gombokhoz és kiemelésekhez.
- Font: 'PT Sans' (sans-serif) a tiszta és olvasható megjelenésért, mind a főcímekhez, mind a szövegekhez. Note: currently only Google Fonts are supported.
- Kártya alapú elrendezés a kaptárak listázásához.
- Reszponzív design a mobilra optimalizáláshoz.
- Méhészeti témájú ikonok használata az alkalmazásban.
